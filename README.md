# 오늘 뭐 먹지? 메뉴판 돌림판

대학생을 위한 메뉴 선택 룰렛입니다. 학식, 학교 앞 맛집, 야식 프리셋으로 시작해 메뉴를 편집하거나 나만의 프리셋을 저장할 수 있습니다. Canvas 2D 룰렛이 메뉴별 가중치에 맞춰 회전하고, 결과를 팝업으로 보여줍니다. 설정은 브라우저의 로컬 저장소에 보관됩니다.

## 사용법

1. 저장소를 내려받거나 복제합니다.
2. 프로젝트 폴더에서 `index.html`을 브라우저로 엽니다. 별도의 패키지 설치나 서버 실행은 필요하지 않습니다.
3. 프리셋을 선택하고 메뉴 이름, 가중치, 색상을 편집합니다. 메뉴는 2개 이상 20개 이하로 구성할 수 있습니다.
4. `+ 메뉴 추가`로 메뉴를 넣고 각 메뉴의 `×` 버튼으로 삭제합니다.
5. 입력란에 이름을 적고 `+ 저장`을 눌러 현재 메뉴 구성을 새 프리셋으로 저장합니다. 선택된 프리셋은 `삭제` 버튼으로 제거할 수 있습니다.
6. `돌려돌려!` 버튼을 눌러 룰렛을 실행합니다. 결과 창에서 다시 돌리거나 닫을 수 있습니다.
7. 메뉴와 프리셋 변경은 이 브라우저의 `localStorage`에 자동 저장됩니다.

## 기술

- HTML, CSS, Vanilla JavaScript
- Canvas 2D와 `requestAnimationFrame`을 이용한 룰렛 렌더링 및 회전 애니메이션
- 브라우저 `localStorage`를 이용한 프리셋과 메뉴 설정 저장
- 모바일과 데스크톱 화면에 대응하는 반응형 레이아웃
